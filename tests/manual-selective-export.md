# 选择性导出验收

参考幕布项目 36a76c5、48e2c76、7a41f29、84c24c4 的目录/任务分离与设置子页面交互，按石墨 API 和跨浏览器兼容层实现。

## 自动验证

```bash
npm test
npm run build:all
```

测试使用模拟 API 和下载函数，不会访问真实石墨账号。覆盖目录隔离、同名文件夹、空/无效选择、权限过滤、全量/选择任务切换、失败重试、暂停恢复、取消、扫描失败、存储失败和旧状态兼容。

## 合成页面

构建后运行 `node tests/preview-server.js`，打开终端给出的本地 URL。页面包含 3,505 篇合成文档、同名目录、子目录、空目录、无下载权限文件和不支持的类型。刷新/重载会保留选择，但进程退出后合成数据消失。不会下载真实文件。

- 勾选第一个同名文件夹：选择包含子目录的 3,502 篇可导出文档；第二个同名文件夹不被选中。
- 父目录显示半选；空目录及两个不可导出的文件禁用。
- 展开大目录：每次显示 100 个子节点，“显示更多”继续追加；清空、全选和折叠展开后状态保持正确。
- 刷新目录和重载页面：保留有效选择；删除或不可导出的文件不保留。
- 选择一篇文档后开始：任务总数为 1，完整目录仍为 3,505。
- 可在控制台通过 `preview.rpc('__failDocument', {id:'doc1', fail:true})` 模拟下载失败，改为 `false` 后重试。
- `preview.rpc('__failNextWrite')` 模拟下一次保存失败：出现错误且不能开始；重新勾选可恢复。
- 导出中暂停、继续、取消：任务不会扩大范围；取消保留目录和选择。
- 1280px 与 390px 视口无横向溢出，文件标题按文本显示，Tab 可操作复选框及按钮。
- `/popup.html` 的“选择导出”入口指向 `settings.html#select-export`（预览仅记录在 `previewOpenedURL`，不实际打开新窗口）。

## 成功反馈合成验收

- 从当前选择页开始一个文档的导出：全部成功后出现祝贺、数量、“约省下 15 秒”和“完成”按钮；五星从左到右约 0.8 秒填满，全屏撒花持续约 5 秒。
- “完成”、Escape 或点击遮罩均可关闭，焦点返回导出按钮；提前关闭不截断撒花的原定持续时间。
- 关闭后刷新页面，不再次展示历史成功；重复任务通知不重播。
- 模拟失败不弹窗，解除模拟失败后重试全部成功才弹；取消、暂停或仍有待处理项不弹。
- 点击“不再提示评价”后，后续成功仍有五星、撒花、省时提示及被动“去评价”链接，但不再显示邀请和取消提示按钮。
- “去评价”指向石墨插件评价页，点击后保存共享的 ratingDismissed 偏好；预览仅记录 previewOpenedURL，不打开真实商店或提交评价。
- 保存偏好失败时显示错误，不误隐藏提示；重试可恢复。
- 开启系统“减弱动态效果”：不撒花，五星静态填满，成功确认仍可操作。
- 1440px 桌面与 390px 窄屏均可完整查看弹窗，无横向溢出。
- 在 `/popup.html` 收到选择任务结束事件时，不重复出现原有的评价邀请。

## 真实扩展验收

1. 在对应浏览器加载 `dist/chrome`、`dist/firefox` 或 `dist/edge`，保持已登录石墨。
2. 从旧版本升级后先刷新一次目录，检查个人空间与团队空间、空目录和同名目录。
3. 先选择少量有导出权限的文档，确认文件名、实际内容、下载层级与格式设置。
4. 运行中从弹窗与设置页交替操作暂停/继续；关闭页面后再次打开，核对任务范围。
5. 失败重试只导出当前任务失败项；选择任务结束后再全量导出，应使用完整目录。
6. 目录读取失败应保留旧目录，并显示错误，不能用部分结果替换完整目录。

真实石墨登录、接口行为、浏览器下载及 service worker 的实际挂起恢复需要在对应浏览器中验收；合成测试不替代这部分。

## 团队权限与共用页面回归

- 团队在线文档带 `permissions.downloadable: false` 或 `permissionsAndReasons.canDownload.value: false` 时仍可勾选，实际导出由转换接口授权；接口拒绝时应记录失败，不弹成功页。
- 同样标记的上传附件/PDF/ZIP 仍显示无下载权限，不可勾选。已有目录缓存也应按同样规则处理。
- 选择导出、popup 和导出设置使用同一套图标下拉框；选择后保存，重新打开显示保存值；鼠标、上下方向键、Enter、Escape 均可操作。导出/扫描中选择页格式锁定。
- 设置页全部 5 个 tab 都有赞赏与小提示，窄屏转到内容下方；检查二维码可见、无横向溢出。
- popup 账号按钮显示姓名首字，点击展开账号浮层；检查已登录、401/403、网络失败及重试状态，Escape/外部点击关闭，登录和石墨首页链接正确。

- 账号返回 avatar 时显示真实圆形头像；缺失/图片加载失败时显示昵称首字；刷新账号或登录失效后，旧头像的延迟回调不得覆盖当前状态。

- 真实头像回归须在扩展页面（不是普通网页预览）验证：uploader.shimo.im 跳转 oavatar.shimonote.com 后应加载成功。规则仅匹配本扩展的 HTTPS 图片请求，并等待规则安装后再显示账号；普通网页和导出请求不匹配。Firefox最低版本为113。
